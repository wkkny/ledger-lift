# Ship as a desktop app that manages Ollama

Ledger Lift is a desktop app (first built with Tauri; ADR 0003 moved it to Electron), not a Python script serving a web page. The app starts Ollama, pulls the model with visible progress, and keeps the model loaded between pages, so the owner never opens a terminal and the first page after a break doesn't wait for a model load. Ollama itself still comes from its official installer; we chose not to bundle our own inference engine, which would mean a multi-gigabyte installer and much more work. Tauri was chosen over Electron because its small footprint leaves more of the owner's memory and CPU for the model, at the cost of a Rust backend. This refines ADR 0001: the owner no longer runs the model by hand, but extraction still happens on their computer.
